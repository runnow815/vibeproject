# 《泡泡堂 / Q版泡泡堂》道具清单

> 资料口径：以盛大《泡泡堂》官方合作专区（52PK）与游侠网《泡泡堂道具详细介绍篇》为主，
> 补充 Q 版小游戏（4399 一类网页版）中常见的变体道具。不同版本、不同地图的道具池会有出入，
> 表中已标注差异；最后一节对照本作（`泡泡对战`）的实际实现。

## 一、属性成长类（最核心的三件套）

| 道具 | 效果 | 常见获取方式 |
| --- | --- | --- |
| 泡泡（蓝色泡泡） | 可同时放置的泡泡数量 +1（有上限，通常 5～6 个） | 炸开木箱随机掉落、地图固定刷新 |
| 药水（力量水 / 威力药水） | 泡泡爆炸的水流长度 +1 格 | 炸开木箱随机掉落 |
| 旱冰鞋（轮滑鞋 / 飞鞋 / 速度鞋） | 移动速度 +1 级 | 炸开木箱随机掉落 |
| 大力丸（超级药水） | 泡泡威力直接拉满（一次到最大射程） | 炸开木箱（低概率）、特殊宝箱 |

> 这三件是「炸弹人」类玩法的通用成长线，也是 Q 版网页版里最常见的三种掉落
> （分别对应图标：多个泡泡叠在一起 / 装着蓝色液体的瓶子 / 一只旱冰鞋）。

## 二、功能类（改变操作方式）

| 道具 | 效果 | 常见获取方式 |
| --- | --- | --- |
| 手套（拳套） | 可以把已放下的泡泡举起来扔出去 | 炸开木箱 |
| 运动鞋（踢鞋） | 可以用身体把泡泡踢走 | 炸开木箱 |
| 弹簧鞋 | 按 `Ctrl` 使用，可跳过一格障碍或跳出包围圈 | 炸开木箱、商城 |
| 透明水 | 按空格放下泡泡时，泡泡近乎隐形，对手很难察觉 | 炸开木箱 |
| 隐身衣 | 一段时间内身体半透明，对手难以判断位置 | 炸开木箱、商城 |
| 面具（化装服） | 一段时间内变成对方队伍的颜色，混战中制造混乱 | 炸开木箱 |
| 针 | 被关在泡泡里时使用，立刻自行脱困（新手必备） | 商城购买、活动赠送（属于消耗品） |
| 飞镖 | 远程瞄准投掷，让指定泡泡立刻爆炸 | 商城购买、炸开木箱（部分地图） |
| 解毒药 | 中了「恶魔」的负面效果后使用，立刻解除 | 商城购买 |

## 三、特殊 / 负面类

| 道具 | 效果 | 常见获取方式 |
| --- | --- | --- |
| 恶魔（红色魔头） | 速度拉满，同时可以踢开身边的泡泡 | 炸开木箱（低概率） |
| 蓝色魔头 | 负面道具：一种是「乱投泡泡」（不受控地自动放泡），一种是「逆向走路」（方向键左右颠倒） | 炸开木箱（陷阱类） |
| 神秘箱子 | 随机开出增益或减益，高风险高回报 | 地图固定刷新点 |

## 四、坐骑类（多一条命）

| 道具 | 效果 | 常见获取方式 |
| --- | --- | --- |
| 乌龟 | 可骑乘，速度变慢，但**多一次生命**；运气好遇到海盗红乌龟则速度极快 | 炸开木箱 |
| 猫头鹰 | 可骑乘，速度略快，多一次生命 | 炸开木箱 |
| 飞碟 | 可骑乘，速度很快，多一次生命 | 炸开木箱（低概率） |

| 破飞碟 | 摇摇晃晃，速度和乌龟差不多，需要「扳手」修好才能变快 | 特定地图掉落 |

## 七、常见获取方式汇总

1. **炸开木箱掉落**：最主要来源，比例通常按「泡泡数量 / 威力 / 速度」优先，稀有道具（大力丸、飞碟、恶魔）概率很低。
2. **地图固定刷新点**：神秘箱子、部分高级道具会在固定点位定时刷新，先到先得。
3. **商城购买**：针、飞镖、通行证、喇叭等消耗品与外观（头饰、服饰、多彩泡泡、旗帜、表情）。
4. **活动 / 礼包 / 通行证**：限时道具、双倍金币卡、隐藏地图入场券。
5. **坐骑**：只能靠地图掉落，不可购买，是「多一条命」的关键资源。

## 八、本作（`泡泡对战`）的实现对照

当前版本实现了三件核心道具，掉落率 36%，三种道具权重约为 `炸弹 40% / 火力 38% / 速度 22%`：

| 本作道具 | 对应原作 | 效果 | 上限 |
| --- | --- | --- | --- |
| 炸弹（黑色小球图标） | 泡泡 / 蓝色泡泡 | 可同时放置的炸弹 +1 | 6 |
| 火力（火焰图标） | 药水 / 力量水 | 爆炸冲击长度 +1 格 | 7 |
| 速度（闪电图标） | 旱冰鞋 / 速度鞋 | 移动速度 +1 级（每级缩短 18% 单格耗时） | 3 |

未实现但数据结构已预留的方向：手套（扔泡）、踢鞋（踢泡）、针（自救）、弹簧鞋（跳障碍）。
