# 泡泡对战 · 使用说明

> 适用版本：v1.1.0 · 更新日期：2026-10-20
> 面向玩家与部署者的操作手册。功能清单与设计说明见 [功能增强说明](./功能增强说明.md)。

## 1. 启动游戏

```bash
npm install     # 首次运行安装依赖（仅 ws 一个运行时依赖）
npm start       # 默认监听 http://localhost:3000
```

自定义端口与房间上限：

```bash
PORT=8080 MAX_ROOMS=200 npm start
```

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | 3000 | HTTP / WebSocket 监听端口 |
| `MAX_ROOMS` | 500 | 服务器同时存在的房间数上限，超出后创建失败 |

打开 `http://localhost:3000` 即可进入首页。健康检查接口：`GET /health`。

## 2. 基本操作

| 动作 | 键盘 | 触屏 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左侧虚拟方向键 |
| 放炸弹 | 空格 / J / K | 右下角炸弹按钮 |
| 挣脱眩晕 | 狂按方向键 | 狂点方向键 |

- 被炸中不会立刻死亡，而是**眩晕**；狂按方向键可以提前挣脱，队友靠近也能救。
- 炸掉木箱可以拾取道具：火力（火焰更长）、炸弹（可同时放更多）、速度（走得更快）。

## 3. 开一局

1. 首页输入昵称（≤ 8 字，留空自动生成"泡泡+数字"）。
2. 选择模式：
   - **玩家对战**：2–4 名真人；
   - **混合对战**：真人 + AI 各占席位，凑不齐时 AI 补位自动开局；
   - **人机对战**：1 名真人 + 3 个 AI，立即开战。
3. 混合 / 人机模式可再调 AI 难度（简单/普通/困难）、AI 数量、混战或 2v2 分队。
4. 点 **快速匹配**（自动并入等待中的房间）或 **创建房间**。

## 4. 邀请朋友

房间页提供两种方式：

- **复制邀请链接**：点击后链接形如 `http://你的地址/?room=AB2C`，已复制到剪贴板，直接发给朋友。对方打开后房间号会自动填入，点「加入」即可。
- **房间号**：直接把 4 位房间号告诉对方，在首页输入框填入后点「加入」。

说明：

- 房间号由字母和数字组成，**不含 I、O、0、1**（避免看错），例如 `AB2C`。
- 浏览器不允许自动复制时（常见于非 HTTPS 或旧浏览器），页面会显示一个只读链接框，长按 / 选中即可手动复制。
- 自己页面地址栏会随房间同步 `?room=`，刷新页面后房间号仍在。

## 5. 房间聊天

- **什么时候能聊**：仅在房间**等待阶段**可发送；开局后输入框自动禁用，避免分心。
- **怎么发**：点快捷语一键发送，或在输入框打字后回车 / 点「发送」。
- **限制**（防止刷屏，客户端与服务端双层限制）：
  - 每条最多 **40 个字**（含表情，按 Unicode 码点计数）；
  - 客户端每 **0.7 秒**最多 1 条；
  - 服务端令牌桶：**4 条额度，每 1.3 秒左右恢复 1 条**（约 0.75 条/秒）；
  - 聊天记录只保留最近 50 条，离开房间即清空，**不会**写进本地存储。
- 聊天内容按纯文本渲染，任何 HTML 标签都会原样显示、不会执行。

## 6. 设置中心

首页右下角「设置」可调整（全部只保存在本机浏览器，不上传服务器）：

| 设置项 | 说明 |
| --- | --- |
| 音效 | 总开关；关闭后完全静音 |
| 音量 | 0–100%，即时生效 |
| 减少动效 | 「跟随系统」或强制「减少」（关闭浮动气泡、面板弹入等装饰动画，方便晕动症用户） |
| 操作提示 | 首页底部的按键说明，觉得碍眼可以关掉 |
| 清空本地数据 | 一键清掉设置与战绩（需点两次确认） |

隐私模式下 localStorage 可能不可用，此时设置只在当前页面生命周期内生效，页面会给出提示。

## 7. 本地战绩

首页右下角「战绩」：

- 只统计**本机最近 20 局**，记录模式、胜负、淘汰数、时长、人数，不记录昵称、房号、对手 id 或聊天内容；
- 顶部汇总：场次 / 胜率 / 最高淘汰；
- **导出 JSON**：把战绩下载为 `bubble-stats-日期.json` 文件；
- **清空战绩**：点两次确认后删除。

## 8. 断线重连

- 网络闪断后客户端自动重连（指数退避），并凭本标签页的会话 id 恢复房间与进行中的对局；
- 顶栏显示连接状态：在线 / 连接中 / 断线重连中；
- **同一浏览器开多个标签页 = 多个独立玩家**（会话按标签页隔离）。

## 9. 常见问题

**Q：朋友点邀请链接提示房间号无效？**
A：链接里的房间号格式不对或房间已解散。房间号区分大小写且不含 I/O/0/1，直接把 4 位房间号发给对方手动输入即可。

**Q：加入房间没反应？**
A：确认房间号 4 位且未打错字符；若房主已离开，房间会自动解散，需要对方重新创建。

**Q：聊天发不出去？**
A：三种可能：对局进行中（等本局结束）；发太快（等 1 秒左右）；网络断线（消息会在重连后尝试发送，但重连失败会丢弃）。

**Q：设置保存了但刷新后丢失？**
A：浏览器处于隐私模式或禁用了站点数据存储。改用正常窗口即可。

**Q：手机上聊天框被键盘挡住？**
A：输入框会自动滚动到可视区域中间；若仍被遮挡，手动上滑页面。

## 10. 运行测试

```bash
npm test            # 7 个单元/协议测试（游戏规则、AI、阵容、网络协议、混合模式）
npm run test:server # 服务端校验 / 存储 / 聊天协议 / 健壮性（先启动 npm start 或并行跑会自动用独立端口）
npm run test:browser# 真实浏览器验收：平滑度、画布、响应式布局、v1.1 体验增强
```

> 浏览器测试需要本机安装 Edge（默认路径）或改脚本里的 `EDGE` 路径；`test:browser` 前需先 `npm start`。
