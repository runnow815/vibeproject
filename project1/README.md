# Contact v1 · 红蓝对决

基于纯 HTML/CSS/JavaScript 的 Canvas 回合制战术对战游戏。零外部依赖，单文件运行。

**文件：** `contactv1.html`

## 快速开始

直接在浏览器打开 `contactv1.html` 即可：

```bash
start contactv1.html
```

无需安装、无需构建、无需服务器。

## 游戏模式

| 模式 | 说明 |
|------|------|
| **人机对战** | 玩家控制红队，AI 控制蓝队 |
| **双人对战** | 两名玩家轮流操作红蓝双方 |

## 游戏规则

- 每队默认 5 人（可调 3-7 人）
- 回合制，每回合选一名队员行动
- **操作**：点击选中队员 → 鼠标瞄准 → 空格蓄力（力量条来回摆动）→ 松开射击
- **子弹**：从队员圆心发射，**穿透敌人并造成 1 点伤害**，队员移动到子弹落点
- **弹性碰撞**：子弹遇到障碍物、边界或队友会**反弹**，不会停止
- **胜利条件**：全歼对方所有队员

### 兵种系统（可在设置中切换回经典模式）

| 兵种 | 血量 | 特点 |
|------|------|------|
| 突击兵 | 1 HP | 标准参数，全能型 |
| 重装兵 | 2 HP | 体型更大，能量低、衰减快（短射程），能扛一发 |
| 狙击手 | 1 HP | 体型小，能量高、衰减慢（超远射程） |

队员头顶显示血量点，脚下徽标区分兵种；同一颗子弹对同一目标只结算一次伤害。

### AI 难度（仅人机模式）

| 难度 | 行为 |
|------|------|
| 简单 | 随机选人、大角度误差、随机蓄力 |
| 普通 | 锁定最近敌人，按距离精确估算蓄力，小角度误差 |
| 困难 | 视线检测（不朝遮挡方向射击）、优先进攻残血目标、误差极小 |

## 操作说明

| 操作 | 按键/鼠标 |
|------|----------|

## 设置选项

| 设置 | 范围 | 说明 |
|------|------|------|
| 队伍人数 | 3-7 | 每队队员数量 |
| 蓄力速度 | 0.5-2.0 | 力量条摆动速度 |
| 最大距离 | 50%-150% | 子弹最远飞行距离 |
| AI 难度 | 简单/普通/困难 | 仅人机模式生效 |
| 兵种模式 | 兵种/经典 | 经典 = 全员 1 HP 突击兵 |
| 音效 | 开/关 | WebAudio 合成音效 |
| 地图 | 6 种 | 切换不同障碍物布局 |

## 代码架构

单文件 `contactv1.html`，结构如下：

- **CSS (~20 行)** — 全屏 Canvas 样式
- **JavaScript (~1000+ 行)** — IIFE 自执行函数
  - 屏幕系统：menu / game / settings / statistics / load
  - 回合生命周期：select → aim → charge → bullet → resolve
  - 摄像机系统：平移 + 缩放，坐标自动转换
  - 弹性碰撞：边界/矩形障碍物/队友反弹物理
  - 兵种系统：`UNIT_CLASSES` 定义三兵种属性，`initPlayers` 按比例分配
  - AI 逻辑：`startAITurn` 三档难度（含 `hasLineOfSight` 视线检测、`chargeForDistance` 蓄力估算）
  - 音效：`Sound` 对象，WebAudio 振荡器合成
  - 多存档位：localStorage 存储最多 10 个存档（含兵种/血量）
  - 统计持久化：场次、胜率、KD 比

## 关键技术点

- **碰撞系统**：线段与圆的碰撞检测（击杀）、矩形碰撞检测（障碍物反弹）、圆心方向反弹（队友）
- **反弹物理**：世界边界 → 速度分量取反；障碍物 → 判断最近边反弹；队友 → 从圆心方向反射
- **摄像机**：`screenToWorld()` 坐标转换，`withCamera()` 统一渲染变换
- **蓄力机制**：力量值在 0-100 之间来回摆动，松开时定格
