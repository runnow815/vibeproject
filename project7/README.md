# 飞机大战 · Sky Raid

一个零依赖、单文件的纵版飞行射击网页游戏，双击 `plane.html` 即可离线游玩。

![Shooter](https://img.shields.io/badge/依赖-零-blue) ![License](https://img.shields.io/badge/license-MIT-green)

## ✨ 特性

### 关卡与 Boss
- 🗺 **8 个设计关卡**（平原巡航 → 最终决战），每关有独立小怪组合、击坠配额与专属 Boss；通关后进入**无尽空域**持续爬升难度
- 🚨 击坠配额达成后 Boss 降临（弹幕警告 + 顶部血条），Boss 按血量分**三阶段**：瞄准扇形 → 环形+扇形交替 → 双螺旋弹幕+暴走
- 💥 Boss 击破必掉 `P` 火力 + `H` 生命 + `B` 炸弹，并给予大额奖励分

### 小怪（7 种，全部会开火）
| 类型 | 行为 |
| --- | --- |
| 侦察蜂 small | 直落，过警戒线概率单发瞄准弹 |
| 毒尾蝎 zig | 蛇形横移，周期瞄准弹 |
| 铁甲兽 tank | 慢速高血量，向下三连扇形弹 |
| 俯冲鬼 darter | 进场悬停瞄准后向玩家位置高速俯冲（俯冲前单发） |
| 炮艇 gunner | 顶部悬停横向巡逻，三连扇形瞄准弹，限时后撤离 |
| 分裂体 splitter | 死亡裂解为两架小型机 |
| 精英 elite | 高血量环形 12 向弹幕（第 5 关起） |

### 其他
- 🎁 道具：`P` 火力升级（三档）/ `B` 炸弹 +1 / `S` 护盾 / `H` 生命 +1；满时转化为加分
- 💣 炸弹清屏（J 键）：清除全部敌弹、重创全场小怪与 Boss
- ❤️ 生命 ×3（上限 5）：中弹掉火力并进入无敌闪烁；护盾挡一次
- 📊 HUD：关卡进度（击坠 x/配额 或 Boss 血量 %）、顶部 Boss 血条、关卡横幅
- ✨ 爆炸粒子、浮动得分、滚动星空、尾焰动画
- 🔊 WebAudio 合成音效（射击/命中/爆炸/警报/拾取/炸弹/通关），可开关
- 💾 最高分本地保存（localStorage）
- 📱 响应式布局：画布按视口宽高等比缩放（手机竖屏/横屏、桌面矮窗口均完整可见），触屏设备提供虚拟炸弹/暂停按钮、拖动时飞机自动上偏避免手指遮挡
- ⚡ 零依赖，单 HTML 文件，无需安装

## 🕹 操作

| 按键 / 操作 | 功能 |
| --- | --- |
| 鼠标移动 / 触摸拖动 | 飞机跟随（缓动） |
| ↑ ↓ ← → / WASD | 键盘移动 |
| J | 释放炸弹 |
| P / Esc | 暂停 |
| R | 重新开始 |
| 空格 / Enter | 开始 / 继续 / 通关后进入无尽 |

射击全自动，专心走位躲避弹幕即可。

## 🛠 逻辑验证

碰撞、关卡配置、敌机/Boss 属性、弹幕生成、掉落概率独立在第一个 `<script>` 块并通过
`module.exports` 暴露，可在 Node 中验证：AABB/圆碰撞、8+ 关卡配置单调性与无尽缩放、
7 种小怪属性合法性、Boss 三相位阈值、扇形/环形弹幕数量与角度、含 H 的掉落分布。
