# 墨战 · 水墨城池攻防

一个零依赖、单文件的水墨风 State.io 类 RTS 策略网页游戏，双击 `inkwar.html` 即可离线游玩。城池自动产兵，框选派遣、攻城略地，配合战术卡牌以弱胜强——笔落惊风雨，一局定江山。

![InkWar](https://img.shields.io/badge/依赖-零-blue) ![License](https://img.shields.io/badge/license-MIT-green)

本项目按「先文档后代码」开发：完整需求文档（含流程图与原型线框）、架构设计与可视化原型页见 `docs/`。

## ✨ 特性

### 核心玩法（State.io 同源 + 墨战差异）
- 🏯 **城池攻防**：8~14 座城池自动产兵（3 级，增援抵达自动升级、容量封顶），框选/点选己方城池 → 点击目标派遣 50%/100% 兵力 → 来犯兵力超过驻军即占领
- 🖌 **字兵建模（v1.2/v1.3）**：部队与城池驻军都以「兵」字呈现——行军**有多少兵显示多少字**，驻军**环绕城池**（容量封顶、慢旋）；城池等级一/二/三级大小分明并标注人口上限；阵列兵派走/散尽后「屯」图消失
- ⚔️ **军令改向（v1.2）**：行军途中点选/框选部队，点击新目标即改向（拖拽可快速改道），点空地=改道列阵
- 🖌 **墨色相溶**：不同阵营的部队在行军途中相遇（碰撞体积相接）即**互相湮灭**——拦截敌方增援成为正式战术
- 🏕 **屯兵列阵**：点空地可将部队驻扎待命，之后可再次框选派遣；阵列每 5 秒散逸 1 兵（墨迹风化），蓄兵是双刃剑
- ⚔️ **胜负**：占领全部敌方城池获胜；己方城池尽失则败

### 战术卡牌（8 张次卡）
| 卡名 | 墨量 | 效果 |
| --- | --- | --- |
| 火攻 | 5 | 烧毁敌城四成驻军 |
| 护盾 | 4 | 己方城 8 秒免疫来犯 |
| 增援 | 4 | 目标己城 +25 兵 |
| 虚弱 | 4 | 敌城产速减半 10 秒 |
| 疾行 | 3 | 己方行军速度 ×2（10 秒） |
| 借刀 | 6 | 最近的中立城倒戈为己方 |
| 围魏救赵 | 5 | 敌方在途部队全部折返 |
| 墨涌 | 6 | 己方全城 +8 兵 |
| 策反 | 6 | 敌城三成驻军倒戈，化为己方部队就地攻城 |
| 固守 | 5 | 己城产速 ×3 持续 8 秒 |

墨量随时间与占领增长（上限 10），3 卡槽循环摸牌。中立城不产兵——没人占领的城池驻军固定，扩张窗口稍纵即逝。

### 模式与 AI
- 👥 **好友对战（联机 1v1）**：创建房间生成邀请链接，朋友点开即加入；WebRTC P2P 直连 + 主机权威同步，静态托管即可玩，无需服务器
- ⚡ **快速对战**：对手 1~3、地图小/中/大、难度三档自由组合，3~5 分钟一局
- 📜 **闯关 10 关**：城池数与 AI 强度递进，逐关解锁，进度持久化
- 🤖 **三档 AI**：扩张 → 回防 → 升级 → 前线集结 → 进攻 → 满仓保底强攻六段决策，与玩家共用同一命令接口、不作弊；失误只「选错目标」不无脑送兵；困难 AI 会视战局使用固守/策反/火攻
- 🧪 **无头验证**：模拟核心为纯逻辑层（固定 1/30s 步长 + 命令驱动），`node tools/verify-sim.js` 56 项断言全绿（地图生成/占领/升级/8 张卡/阵列/遭遇战/状态不变量/AI 难度分层采样）

### 表现与工程
- 🎨 水墨视觉：宣纸底、远山笔触、四阵营墨色（朱砂/黛青/赭石/黛绿）、楷体、印章结算、占领晕染双环
- 🔊 WebAudio 合成音效（点选/出兵/占领/升级/卡牌/胜负），可开关
- 💾 localStorage 持久化：闯关进度、最快胜利、音效、上次对战配置（前缀 `ink.`）
- 📱 响应式：画布三重约束（视口宽/高 × 宽高比），手机竖屏/横屏、桌面矮窗口均有专属布局；触屏拖框、控件热区 ≥ 44px
- ⚡ 零依赖，单 HTML 文件，无需安装；菜单背景就是一场实时 AI 混战
- 🌐 **在线游玩**：https://runnow815.github.io/vibeproject/project8/inkwar.html （GitHub Pages 自动部署）

## 🕹 操作

| 鼠标 / 触屏 | 功能 |
| --- | --- |
| 点击己方城池 | 选中 / 取消选中（可多选） |
| 按下拖动（空白处） | 框选全部相交的己方城池与阵列 |
| 按下拖动（从己方城池出发） | 直接向落点派遣（带兵力预览） |
| 选中后点击敌方/中立城池 | 进攻 |
| 选中后点击己方城池 | 增援（可触发升级） |
| 选中后点击空地 | 出兵列阵屯兵 |
| 50% / 100% 按钮 | 切换派遣比例 |
| 点击卡牌 → 点击城池 | 发动战术卡（再点卡/点空白取消） |
| 空格 / ‖ 按钮 | 暂停 / 继续 |
| Esc | 取消卡牌瞄准 / 暂停 |

## 🛠 逻辑验证

模拟核心（数值配置、地图生成、命令与战斗结算、8 张卡牌、AI 决策）独立在第一个 `<script>` 块并通过 `module.exports` 暴露：

```bash
node tools/verify-sim.js
```

覆盖：地图生成约束与同种子确定性、派兵/占领/升级/容量封顶、在途遭遇湮灭、8 张卡牌效果与目标合法性、阵列创建/散逸/再派遣、双玩家独立手牌与视角化胜负、完整对局必出胜负与幂等冻结、每 100 步状态不变量抽样、困难 vs 容易 AI 40 局采样（胜率 / 无僵局 / 遭遇战发生 / 对局时长）。联机链路（信令/快照同步/指令闭环）由双标签页端到端实测覆盖。
