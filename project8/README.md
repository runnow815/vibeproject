# 墨战 · 水墨城池攻防

一个零依赖、单文件的水墨风 State.io 类 RTS 策略网页游戏，双击 `inkwar.html` 即可离线游玩。城池自动产兵，框选派遣、攻城略地，配合战术卡牌以弱胜强——笔落惊风雨，一局定江山。

![InkWar](https://img.shields.io/badge/依赖-零-blue) ![License](https://img.shields.io/badge/license-MIT-green)

本项目按「先文档后代码」开发：完整需求文档（含流程图与原型线框）、架构设计与可视化原型页见 `docs/`。

## ✨ 特性

### 手机端与视野（v1.27 双指缩放 + 竖屏重排 · v1.28 触屏操控放大 · v1.37 布局重做 · v1.38 单指拖动）
- 🖐 **单指拖动地图（v1.38）**：手机上**一根手指就能拖动战场**。旧实现只有双指缩放平移，单指拖空白被框选占用 —— 玩家怎么拖都拖不动，这是「手机上不能拖动」的根因。现在触屏**单指拖空白 = 平移地图**，框选退到「长按 300ms 后拖」（与卡牌长按看详情同一套交互语言），从城/兵拖出仍是派遣。**桌面鼠标拖空白仍是框选，语义零回归**
- 📐 **棋盘再放大（v1.38）**：竖屏 `--board-ar-min` 从 `.9` 放宽到 `.62`（旧值在 390×844 下把舞台卡死在 416px，剩 116px 变成上下死白），并把**一直占位却用不了的比例条**在无可出兵选中项时收起（省 73px）。iPhone13 竖屏棋盘占高 **49% → 72%**，8 档实测 **60%~78%**（极窄屏 46% → 60%），地图元素同时放大约 30%
- 🏠 **开局不再把家裁到屏外（v1.38）**：画布变瘦长后 cover 裁切加剧，复位回到「地图几何中心」时屏内一座己方城都没有。现在复位/开局**居中己方主城**（未裁切时 `viewClamp` 把偏移钳回 0，桌面 16:9 与旧版逐像素一致）
- 📐 **移动端布局重做（v1.37）**：竖屏舞台改 `flex:1 1 auto` + `min-height:0`，画布 `position:absolute` **铺满舞台**（不再按 `--board-ar` 反推高度），把原先上下合计 300px 的死白全部还给棋盘 —— iPhone13 竖屏占屏高 **33% → 49%**（v1.38 进一步提到 72%）。断点加 `orientation:portrait` 限定（此前 640×360 横屏会同时命中竖屏与横屏两套规则）。新增 `--board-ar-min` 闸门，画布最多允许多瘦可被限制，不会裁切过头
- 🔎 **屏内缩放条（v1.37）**：触屏（`(pointer:coarse)`）在棋盘右上角显示 **＋ / － / ⤢ 回正** 三键，44×44 热区，与双指手势共用同一套钳制（`viewZoomStep` / `viewFit`）；桌面端不出现，零回归。配合左下角缩略图，单手也能完成「放大看细节 → 回正看全局」
- 👆 **文字与热区（v1.37）**：修掉一个 CSS 级联 bug —— `@media (pointer:coarse){.card{min-height:44px}}` 源码里排在断点**之后**，把竖屏的 76px 覆盖成了 44px（**触屏手牌比桌面还矮**）；现改用更高特异性的 `.cardbar .card`。窄屏提示 11.5 → 12.5px、牌堆 10.5 → 11.5px；侧栏 180 → 196px，横屏卡片 44 → 52px、提示 16 → 48px
- 🤏 **双指缩放 / 平移（v1.27）**：双指张开捏合缩放战场（1~3.2×），双指拖动平移视野；桌面滚轮以光标为锚点缩放。基准 fit 由原来的 **contain（留黑边）改成 cover（铺满）**，手机竖屏画布比例从 16:9 放宽到 **1.35**，棋盘占屏高从 25% 提到 **33~40%**（8 档机型实测）。**单指手势语义一字未改**——缩放平移只走双指，选兵 / 派遣 / 框选完全不受影响
- 👆 **触屏操控放大（v1.28）**：点按/拖动阈值与命中容差改按 **CSS 像素**标定，粗指针（手指）再放大——手机竖屏旧阈值实际只有 5~7 CSS px（点不中兵、手指轻抖就误判成拖拽出兵）；**胖手指补偿**：触屏点按按「落指」位置判定意图，抬手滑出 10~20px 也能点中想点的兵。屏内方向键按钮触屏放大到 44px（≥最小触控热区）。桌面（鼠标）语义不变。CDP 真机触摸模拟实测：点中驻城兵 / 抖动不出兵 / 按住方向键持续行军 / 松手驻扎 全链路通过
- 🗺 **缩略图与复位（v1.27）**：视野被放大或被裁切时，左下角自动浮出**缩略图**（全图城池点 + 朱砂视口框），补回「铺满」裁掉的两侧；左上角出现 **⤢** 徽标，点它或按 **0** 一键复位。开新局自动复位，不把上一局的缩放带进下一局
- 🎓 **新手难度梯度（v1.27）**：新增**入门**难度档（闯关 1~2 关 + 快速对战可选），与休闲 / 标准 / 困难 / 宗师共 **5 档**。取向不是「打得更慢」，而是「**敢打但打不准、也守不住**」——出兵门槛极低（池 5 / buffer 0.5）保证家里不留厚壳（厚壳对新手才最难啃），但六成决策选错目标、不用牌、不拦截。实测（n=400×2 种子族，玩家侧由同难度 AI 代打）：第 1 关弱玩家胜率 **48% → 64%**，中玩家 91%，且我方被占城数 2.2 < 旧版的 3.5（压力更小）
- 📶 **十五关梯度抹平（v1.27）**：重排为「入门 ×2 → 休闲 ×4 → 标准 ×4 → 困难 ×5」，敌方初始加成改 0/5/10/15/20 五档细步，消掉原先「第 6 关加成 0→10」「第 9 关休闲→困难 + 敌数 2→3」两处跳崖；第 4 关不再「敌数 +1」与「城池 +1」同时发生，第 7 关限时 180 → 240 秒

### 联机（v1.26 · 同步 / 手感 / 连接 / 规则全面重做）
- 🔗 **短联机码（v1.26）**：联机码走「**SDP 白名单裁剪** → **高频前缀令牌替换** → **base64url**」三步无损瘦身，浏览器支持时再叠一层 `deflate-raw`（码首字符区分版本：`z` 压缩码 / `s` 裁剪码 / 其余旧版码，**向后兼容**）。实测**缩短 37%（裁剪）~ 60%（压缩）**，微信里不再被截断。连接过程按 ICE 阶段实时播报，20 秒未连通明确报**超时**并给出可操作建议（换同一 Wi-Fi / 手机热点）
- 📶 **心跳与断线宽限（v1.26）**：每秒一次 ping/pong 测**往返延迟**（顶栏实时显示，≤80ms 绿 / ≤200ms 金 / 更高朱砂）；DataChannel 的 `onclose` 在异常网络下可能长时间不触发，故连续 **4 秒无下行包即判定失联** → **暂停对局 + 10 秒重连宽限**（主机不能趁对手掉线单方面推进），重连即续、超时则给出**明确原因**（等待超时 / NAT 阻断 / 对手关闭页面）
- 🎯 **客机手感（v1.26）**：快照新增**断粮 / 屯田**剩余秒数与**伏兵 / 瘟疫 / 临时塔**四个城池字段（尾部追加，新旧版本可互解）——此前断粮期间客机按原速航位推算，位置持续超前再被快照硬拉回，肉眼可见抖动；快照到达后**起点留在旧位置、软目标指向快照位置**（逐帧收敛，抹掉瞬移）；出兵先画一支**本地影子部队**（半透明、不参与任何判定），真身随下一份快照覆盖
- 🛡 **指令权威校验（v1.35）**：联机时主机**不信任网络包里的 `owner` / `type`**，客机的派遣 / 改向 / 分兵 / 全军出击 / 升级 / 出牌一律按「客机 = 2 号阵营」重建后再交给块1（`ratio` 同时钳进 [0,1]）。此前 `send` / `retarget` / `split` 是把收到的 `cmd` 直接丢进 `Sim.command`，客机可以伪造 `owner:1` 的指令调遣房主的兵 —— 现在块1 的归属校验会直接把这些来源判无效
- 📴 **离开页面不再被判断连（v1.35）**：手机来电话、切 App、桌面切标签页都会让 `requestAnimationFrame` 停摆，心跳与快照随之中断 —— 旧逻辑 4 秒后判失联、10 秒宽限耗尽就**直接终止对局**。现在双方用 `away` 包互报状态：离开期间**不累计失联计时、不判定失联、不进倒计时、不判负**，并且**两边一起冻结**（沿用「不能趁对手掉线单方面推进」的老原则）；回来即自动继续（主机立刻补推快照，客机主动索要）。顶栏显示金色「**对手后台**」，与朱砂色的真断线区分开
- 🔁 **断线续连（v1.37）**：断线不再只有「放弃等待」一条路。失联遮罩与断连结算页都给出「**重新连接**」——双方各自点一下，重新交换一次联机码即可**续上本局**（不重开、不重抽地图：主机补推快照、客机索要 `resnap`）。进入续连时**立即撤掉 10 秒宽限倒计时**（慢一点换码不该被判死），并按 `netLastRole` 还原原本的房主/客机角色。手机切 Wi-Fi ⇄ 4G、锁屏再回来不再废局
- 🧊 **ICE 收集不再半途而废（v1.37）**：旧版 `gatherIce` 固定 3.5 秒硬超时，**出码时候选往往还没收集完**，对面少一半可用路径，跨网连不上且无任何提示。现改为等到 `iceGatheringState === 'complete'`（上限 8 秒）并实时播报；新增 `iceStat` / `iceHint`：一个公网候选都没有时明确提示「**全是内网地址 · 跨网大概率连不上**，请连同一 Wi-Fi 或填 TURN」
- 🧭 **联机入口不再被埋（v1.37）**：手机上菜单内容高 1763~2080px、视口仅 548~824px，「创建房间」原本在 **1641~1901px** 处（要滚两三屏），点完房间邀请码输入框又落在 1752px（屏外）—— 联机在手机上等于走不通。现手机竖屏把「好友对战」**排到最前**（首屏可见），写入联机区后自动 `scrollIntoView`
- 🏷 **版本号标记（v1.35）**：主菜单底栏右下角显示当前版本（如 `v1.35`）——块2 内 `APP_VER` 是唯一来源，`window.__ink.ver()` 供自动化核对。**发布后打开线上页面即可一眼确认跑的是哪一版**（此前版本只存在于注释与文档，线上无法自查）
- ⚙️ **房主配置与规则（v1.26）**：等待室可设**地图 / 节奏 / 限时**并实时同步给客机（PVP 双方都是人、没有 AI，难度选项没有意义，故不提供）；客机可**请求暂停**（决定权仍在房主，20 秒无响应给提示）；再战改为**双向确认**（此前客机一按就把主机拽进新局），20 秒无人响应提示可先返回菜单；**联机战绩独立记账**（`ink.netrec`），与单机 `record` / 生涯 `life` 口径分离，互不污染
- 🎫 **房间码联机（v1.39）**：房主点「创建房间」拿到一个 **6 位房间码**（字符表去掉 I/O/0/1，手写口述都不歧义），对手点「加入房间」输这 6 位即可开打 —— 不用再复制 500 字的邀请码、也不用把应答码发回来。SDP 由云数据库的 `rooms` 表自动中转（房主写 offer → 客机回写 answer → 房主 1.2 秒轮询一次），**对局数据仍然走 WebRTC P2P，延迟与以前一样**。房间码一次性（握手完成即作废）、半小时自动失效；分享出去的 `?room=ABC123` 链接点开即填好码
  - 三条边界：① 它只省掉「换码」，**跨网能不能连仍取决于 STUN/TURN**（面板照旧播报候选构成）；② 云服务端做 exact-Origin 校验，**只有线上页面能用**，本地 `file://` 打开会自动退回手动换码；③ SDK 从 CDN **动态**加载（不新增 `<script>` 块，块数恒为 2），加载失败或离线一律降级到「用联机码手动连接（备用）」，不会卡住流程
  - 原两步换码完整保留在「用联机码手动连接（备用）」里（按钮 id 与文案未变）

### 核心玩法（State.io 同源 + 墨战差异）
- 🏠 **回城（v1.36）**：**任意城外部队都能回城** —— 选中城外阵列（屯兵）/ 阵列里的兵 / 在途部队 / 在途的单个兵，点击己方城池即下令回城，抵达后并入驻军（阵列随之撤除，兵力与状态同步）。此前有三处会让「点回城没反应」：① 命中顺序是「点兵 → 点城」，部队/阵列贴着城时点城只选中了一个兵；② 回防只认「整支在途部队」，选中阵列或单兵点己方城只会把城加进选择集；③ 出兵比例为 0% 或来源无兵时，旧逻辑**把选择清空却不派兵、也不提示**。现在派不出兵一律给出明确原因并保留选择
- ⚔️ **过城即接管（v1.36）**：行军**经过敌/中立城池**会开战，**守军被打光（或本就是空城）就顺手接管**（与「点名攻打」同一套结算：改归属 / 进墨 / 记战报 / 剩余兵力转驻军，部队带着剩下的兵继续行军）；守军还在则只是擦过（想拿下仍要点名攻打，R3 不变）。护盾中的城免疫并提示「护盾未破」，兵力不足被守军吃掉时提示「兵力不足」——提示按「同一支部队对同一座城只发一次」节流，不刷屏。玩法说明与天平：A/B 实测（n=160×2 种子族）困难 AI 胜率 58%→75% / 72%→82%，平均时长 -5~10s，僵局数不变
- 🎚 **出兵比例条（v1.34）**：原「50% / 100%」两颗按钮重构为一条完整的选择条 —— **滑块 0~100% 连续调节** + **25 / 50 / 75 / 100% 快捷档位**，右侧读数实时显示「**百分比 — 实际兵力**」（如 `50% — 3,200 兵`，与块1 逐城 `floor(驻军 × 比例)` 的结算口径完全一致，读数即实派）。**未选中己方城池 / 选中来源驻军为 0 或比例越界时整条置灰禁用**并写明原因；选中的城池上方跟随显示当前百分比。布局随端适配：桌面三行竖排、手机竖屏「读数 +（滑块 + 档位）」两行、横屏侧栏收成「读数 + 滑块」单行（180px 放不下档位行，连续调节交给滑块）
- 🃏 **杀戮尖塔式卡牌交互（v1.33）**：卡面精简为**插画 + 名称 + 费用角标**三要素（描述 / 冷却秒数 / 消耗全部移出）；完整详情在**桌面悬停 / 触屏长按 300ms** 时以浮层展示（费用、描述、目标类型、稀有度、冷却、消耗）。出牌改为**拖拽**：需目标的卡拖到合法城池上松手即发动（合法城池脉动朱砂环 + 替身高亮，非法城池红环 + 替身变灰），无目标卡拖出手牌区即发动；松手在非法处 / 拖回手牌区 / 按 `Esc` 都会**回弹取消**。原有的「点卡牌 → 点目标」与 `1~5` 快捷键保留为等价入口
- 🗼 **炮塔索敌补全（v1.32）**：修复「部分炮塔不攻击」——旧索敌只扫描 `sim.armies`（在途部队），完全忽略 `sim.camps`（已驻扎阵列），所以敌军一落地列阵，四种塔都会瞬间“失明”。现改为在途部队 + 阵列统一按距离索敌；炮塔溅射、爪子抓兵、伤亡记账和冷却均复用同一套结算。4 塔 × 6 场景（兵/阵 × 射程内/外/己方）24 格全通过
- 🏯 **士兵进城升级（v1.32）**：己方非满级城外侧新增可点 **↑** 徽章；点中城内士兵后点击徽章或按 `E`，让驻军进入城内完成升级。Lv1→Lv2 消耗 **20 兵**，Lv2→Lv3 消耗 **50 兵**，Lv3 封顶；不足时徽章显示还差几兵并给明确提示。升级走固定步长命令队列，联机由房主校验后通过权威快照同步等级与驻军
- 🎓 **新手引导（v1.25）**：首次进入自动起**九步分步引导**，用「四面遮罩挖洞」高亮讲解顶栏墨量、城池点选、出兵、卡牌、出兵比例、单兵操控、暂停与胜负条件；每步可**跳过**，`ink.tut` 记到哪一步，**断点续接**从那一步继续；末步直接开一局**真实教学对战**（照常给战利品，但不计入战绩 / 闯关进度 / 生涯统计）

### 🎁 卡包：次卡 / 日卡（三选一）
- 每局结算**固定掉落三选一**：候选按概率生成——**次卡高概率**（战术卡，下局开局手牌，用后消耗）、**日卡低概率**（当日被动增益，跨局生效、跨天清空）
- 日卡 5 张被动：屯田（产速+15%）/ 墨泉（墨量回复+50%）/ 铁壁（容量+20%）/ 急行（行军+15%）/ 墨海（墨量上限+2）
- 主菜单卡包面板随时查看持有情况；联机对局中日卡被动不生效（保证公平），次卡正常携带

### 模式与 AI
- 👥 **好友对战（联机 1v1）**：创建房间生成邀请链接，朋友点开即加入；WebRTC P2P 直连 + 主机权威同步，静态托管即可玩，无需服务器
- ⚡ **快速对战**：对手 1~3、地图小/中/大、难度三档自由组合，3~5 分钟一局
- 📜 **闯关 10 关**：城池数与 AI 强度递进，逐关解锁，进度持久化
- 🤖 **三档 AI**：扩张 → 回防 → 升级 → 前线集结 → 进攻 → 满仓保底强攻六段决策，与玩家共用同一命令接口、不作弊；失误只「选错目标」不无脑送兵；困难 AI 会视战局使用固守/策反/火攻（火攻点杀**当前最强的敌对阵营**，多方混战不会集火玩家）

## 🕹 操作

| 鼠标 / 触屏 | 功能 |
| --- | --- |
| 点击己方城池 | 选中 / 取消选中（可多选） |
| 按下拖动（空白处） | 框选全部相交的己方城池、部队与阵列 |
| 按下拖动（从己方城池出发） | 直接向落点派遣（带兵力预览） |
| 选中后点击敌方/中立城池 | 进攻 |
| 选中城池后点击己方城池 | 增援（可触发升级） |
| **选中军队后点击己方城池** | **回防**（并入驻军，v1.18） |
| 选中后点击空地 | 出兵列阵屯兵 |
| 点击城池外侧 `↑` / 选中城内兵后按 `E` | 消耗驻军升级城池：Lv1→2 需 20 兵，Lv2→3 需 50 兵（v1.32） |
| 选中兵/军队 + `W A S D` 或 `↑↓←→` | 持续操控行军，松手就地驻守（v1.15/v1.18/v1.30） |
| 拖动出兵比例滑块 / 点 25·50·75·100 档位 | 连续或按档设定派遣比例；读数实时显示「百分比 — 实际兵力」，未选中己方城池时置灰禁用（v1.34） |
| 选中城外部队（阵列/单兵/在途部队）→ 点己方城池 | **回城**：抵达后并入驻军（v1.36；派不出兵会明确提示原因） |
| **拖拽卡牌 → 在目标城池上松手** | 发动战术卡（v1.33 主入口）。需目标的卡必须落到合法城池；无目标卡拖出手牌区即发动。松手在非法处 / 拖回手牌区 / 按 `Esc` = **回弹取消** |
| 点击卡牌 → 点击城池 | 与拖拽等价的老入口（再点卡 / `Esc` / 点空白取消） |
| 桌面悬停 / 触屏长按 300ms 卡牌 | 弹出详情浮层：费用、描述、目标类型、稀有度、冷却、是否消耗（卡面只显示插画 + 名称 + 费用） |
| 空格 / ‖ 按钮 | 暂停 / 继续 |
| Esc | 取消卡牌瞄准 / 暂停 |
| `1` `2` `3` `4` `5` | 发动对应卡槽的卡牌（等同点击） |
| `Q` | 一键全选己方城池 |
| `E` | 让当前选中的己方城池 / 城内士兵进入主动升级流程 |

> 主菜单与暂停面板均有「? 玩法 / 玩法说明」入口，含目标、操作、快捷键与五条胜负要诀。
