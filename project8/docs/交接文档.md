## 4. 硬性纪律（违反即事故）

1. **恰好 2 个 `<script>` 块** —— 块1 纯逻辑、块2 UI。`smoke-ui.js` 有断言锁住块数，多一个少一个都会红。
2. **块1 不得碰 DOM** —— 必须能在 Node 里 `require` 后跑（`module.exports = InkSim`，第 2048 行）。
3. **零外部依赖** —— 不引 CDN、不装 npm 包、不加构建步骤。
4. **发布只走内置 `workbuddy_sites_deploy`** —— `entryHtml:"inkwar.html"`（目录里还有 `docs/prototype.html`，不填会被选错）、`language:static`、`domainPrefix:inkwar`。**不要发布到 GitHub**（国内访问不行）。
5. **发布前必须重新征得用户同意** —— 授权是一次性的。改完先给本地预览，用户说「上线」才发。
6. **`APP_VER`（第 2074 行）是唯一版本号来源** —— 底栏 `.vtag` 与 `window.__ink.ver()` 都读它。改版本只改这一处。
7. **v1.39 起多了云依赖**：发布时 `workbuddy_sites_deploy` 必须带 `appId: 'wbapp_Oxw6TogrMNVz4o51j4M1qv'`（与云服务同一个应用）。换 appId = 换域名 = 服务端 exact-Origin 校验失败 = 房间码全部失效。

## 5. 架构速览

```
块1 InkSim（纯逻辑，定步长 1/30s，指令驱动）
  CFG(648) / LEVELS(695) / CARDS / RNG×3 / aiTick(1601)
      ↕  Sim.command → cmdQueue → Sim.step 结算
块2 UI（渲染 + 输入 + 联机）
  startGame(3662) → 主循环 → 渲染 → netTick(2594) → showResult(3160)
```

- **逻辑与表现分离**：UI 只能通过 `Sim.command()` 下指令，不能直接改模拟状态。
- **视野变换** `view{z,px,py}` + 基准 cover：`viewPanBy(4573)` / `viewReset(4599)`。
- **联机**：WebRTC DataChannel P2P，**主机权威**。主机跑唯一模拟，10 Hz 全量快照（实测 503 B~1033 B/帧，5~10 KB/s）；客机插值 + 影子部队本地预测。`rtcConfig(6073)`（多家 STUN + 可选自备 TURN）、`gatherIce(6104)`（等收集完成，上限 8 s）。
- **没有信令服务器**：靠「邀请码 ⇄ 应答码」两次人工交换 SDP（短码经裁剪+令牌+base64url+deflate，缩短 37%~60%）。

详细设计见 `docs/架构设计.md`（第 8 节专讲联机）。

## 6. 关键不变量（改代码前必读）

| 不变量 | 说明 |
| --- | --- |
| 增益按阵营记账 | `effects.rushT/starT/starMul/prodT/slowT[owner]`；速度一律走 `Sim.armySpeed(sim,a)` |
| 阵列 `id` 是自增主键 | 不是下标（`sim._pid`），查阵列走 `campById()` |
| 墨上限 / 容量 | 用 `sim.inkMax`（含日卡 +2）与 `Math.round(LEVELS[level-1].cap * sim.mods.cap)`，别写死常量 |
| **`sim.over` = 胜者阵营** | 2 号被清空 → `over=1`；`win = sim.over === mySide`。写胜负断言先确认方向 |
| 三随机源互不串扰 | `rng`（主）/ `trng`（塔掷点）/ `drng`（洗牌）。**新增逻辑若消耗主源，既有断言会集体漂移** |
| 牌堆四堆守恒 | `draw+hand+discard+exhaust === list.length`，`hand.length ≤ CFG.HAND_MAX`；`sim.hands[o]` 与 `sim.piles[o].hand` 是同一数组引用 |
| 卡牌分支按基础 key | `card.base ? card.base : key`，数值走 `cardVal(key)`；同名卡冷却记到期时刻 `sim.cardCd[owner][基础key] = sim.t + card.cd` |

### 表现层三条硬纪律（改卡面前必读）

1. **卡面必须继续用 `innerHTML` 字符串拼接** —— 打桩里 `innerHTML` 只是字符串属性、`querySelectorAll()` 恒返回 `[]`。
2. **新增元素 class 不得以 `card` 开头** —— `match(/class="card/g)` 是前缀匹配；统一用 `inkart` 前缀。
3. **卡面不产出新可见文本** —— 消耗走 `data-ex`、冷却走 `.cn[data-cd]` + `content:attr(data-cd)`。

## 9. 踩过的坑（按代价排序）

**测试与工具**
- **CDP 类脚本偶发红的头号原因是残留 Edge 进程** —— 跑完 `check-mobile` 残留 19 个 `msedge`，紧接着跑 `check-net` 就会红。判 flaky 前先 `tasklist | grep -c msedge`，原样重跑确认，**别急着改断言**。
- **CDP 触摸测试必须先 `__ink.tutSkip()`** —— 新手引导遮罩 `.tutwall` 盖住整块棋盘，此时任何事件都到不了 canvas（表现为「一个 pointerdown 都没收到」）。
- 本机无头 Edge `--dump-dom` 输出为空 → UI 回归只走 `smoke-ui.js`。
- Node 22 的 `global.navigator` 只读 → 打桩用 `Object.defineProperty`。
- CDP 要取 **page 级** `webSocketDebuggerUrl`（`/json/version` 是 browser 级，无 Runtime 域）；用 Node 22 自带全局 `WebSocket` 直连，零依赖。
- `Input.dispatchMouseEvent` 的 `mouseMoved` **也必须带 `buttons:1`**；`window.__ink` **只在 URL 带 `?debug` 时挂载**。
- CDP `setDeviceMetricsOverride({mobile:true})` **不命中 `pointer:coarse`** → 必须再调 `Emulation.setTouchEmulationEnabled`。
- **别猜 DOM id**（本项目没有 `#menu`，菜单是动态渲染的）；可靠自查点是 `__ink.ver()` / `.vtag` / `<script>` 块数 / `#board` 尺寸。

**打桩环境**
- 打桩画布恒 **960×540**（16:9），与地图 1600×900 同比例 → 不裁切、`panBy` 恒被钳回 0。要测裁切须临时改瘦长（如 400×900），**测完立刻还原**。
- `documentStub` **没有 `head`** → 注入 `<style>` 用 `(document.head||document.body||document.documentElement).appendChild`。
- stub 的 `matchMedia` **必须用 getter**（块2 缓存首个 MediaQueryList 进 `mqLand`）。
- 打桩里 `classList` 与 `className` 不联动；`pump()` 不推进对局（用 `I.step(1/30)`）；`aiTick`/`dispatch` 只入队，断言出兵要再 `Sim.step()` 一步。
- `createElement().innerHTML` 后 `firstChild` 恒 undefined → 遮罩须逐个 createElement。
- 打桩 rect 恒 960×540 **会完全遮住布局错位类 bug**（v1.33a 浮层错位就是这么漏的）→ 几何计算必须与真实 CSS 对账。
- `__ink` 里 `Net`/内部变量不可直接访问，需要什么加钩子（`netMsg/setNet/snap/netTick/netGhosts/startCampaign/goalHud/netCh/cmd/netIceStat/netRelink/netWait/side/ptrState` …）。`Net.send` 发 `JSON.stringify` 字符串，捕获端要 `JSON.parse`。
- **段落间会串 `ctrl.id`** → 新操控段落开头先 `I.menu(); click('btnQuick')` 重开一局；段间 `I.sel().splice(0)` 隔离；段间串「出兵比例」→ 开头 `I.ratio(1)`。

**CSS / 布局**
- **CSS 级联**：`@media (pointer:coarse){.card{min-height:44px}}` 排在断点之后，会覆盖竖屏的 76px → 改用 `.cardbar .card` 提高特异性。
- **断点必须带 `orientation`** —— 640×360 横屏曾同时命中竖屏+横屏两套规则。
- 纵向预算的隐形杀手：**灰着不能用却常驻的元素**（`.ratio.off` 占 73 px）、**过紧的 max-height 闸门**（`--board-ar-min:.9` 把舞台卡死）。改纵向布局先量「谁在占地方」，别只调 flex。
- 插画禁用 `defs`/渐变/滤镜/`id=`（data-URI 取不到宿主页 `#id`）→ 纸纹用 CSS 渐变。

**玩法 / 平衡**
- **AI 调优必须「同难度 A/B」或 ≥160 局 × 2 种子族** —— 40 局 ±8 pp 是把噪声当信号；两个种子族能差 18 pp。
- **`JSON.stringify` 会把 `Infinity` 变 `null`**，A/B 造参数别过 JSON。
- 反直觉：**「缩家攒兵的龟壳」反而让弱玩家胜率下降**（48%→42%），厚壳对新手最难啃；改「敢打但不准」→ 64%。
- 限时关别叠在 hard+3 敌「灭敌」上（4%~13% 胜率，再叠超时判负会归零）。

**语法**
- **块1 注释里 `*/` 提前闭合**会让后面的注释变代码 → SyntaxError（在旧注释块后追加多行注释最易犯）。
