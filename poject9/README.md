## 玩法

- 🎯 **目标**：把敌方海盗全部炸飞，或直接轰进海里喂鲨鱼！
- 🏹 **弹簧瞄准**：按住海盗**往反方向拉**，像拉弹弓一样，松手朝反向弹射——拉得越远力越大（带真实弹道虚线预览）
- 🚀 **抛射移动**（工具栏 1 号位，每回合每人 1 次）：拉弓把自己弹飞！落地自动捡道具，撞敌人=神风伤害，落水=出局；移动后同一回合还能继续攻击
- 🗺️ **大地图**：地图宽 1600~2600，鼠标移到画面左右边缘自动平移镜头（手机/触屏则**拖拽空白处**平移）；小地图可点击/拖动跳转（带视口框）；Tab 换人镜头自动跟随
- 💣 **地形破坏**：爆炸炸出带焦痕的凹坑！地面塌了人会掉下去，炸穿岛底敌人会坠海
- 🖱️ **悬停即看**：鼠标压在任何道具/危险物上，弹出说明卡（名称、类别、效果、能否拾取）
- ⌨️ 快捷键：`1`=移动 `2-9`=武器 · `Tab` 换海盗 · `空格` 跳过回合 · `ESC` 返回菜单
- 📱 **手机可玩**：竖屏＝顶部信息条 / 中部战场 / 底部多行工具栏，横屏＝宽屏布局；全部按钮按 44px 以上触控尺寸放大，竖屏视野自动收窄到 480~620 世界单位（看得清人，也还看得到对手）
- 🪶 巫毒娃娃：点敌人锁定后反向拉弓把他弹飞；🍌 香蕉飞行中点击画面引爆；🪂 降落伞开伞后鼠标牵引落点

## 宝箱出现方式（概率明确）

| 通道 | 触发条件 | 概率 / 频率 |
| --- | --- | --- |
| **空投** | 每完成一个整回合计数 +1，达到空投间隔（按难度 3/4/5）时投放；场上同屏最多 1 个未落地 + 2 个空投物，总数 <24 | 每 3~5 回合 1 次，**每第 4 次改为补给箱**（必出，不靠随机） |
| **结构破坏** | 爆炸清除的实体像素 ≥ 80 且距上次掉落 ≥ 0.6s、预算未耗尽、场上破坏掉落物 < 6 | `p = clamp((1−e^(−λ))·面积加成·难度系数, 0, 0.35)`，其中 `λ = Σ 像素数 × 材质速率 / 100`（草 0.0016 / 沙 0.0014 / 岩 0.0009 / 木 0.0045 / 雪 0.0012） |
| **预置** | 关卡数据 `items[]` 声明 | 固定位置 |

> 例：一次炸掉 1250 个木质像素 → λ=0.056 → 约 5.5% 掉一件；同样面积的岩石仅约 1.1%。

## 响应式布局（手机 / 平板 / 电脑）

一套代码三档自适应，**桌面逻辑坐标系恒为 960×560**，所以各端难度与弹道完全一致。

| 档位 | 触发条件 | 画面 | UI 排布 |
| --- | --- | --- | --- |
| `desktop` | 非「窄且竖」也非「矮且横」（含平板） | 960×560 逻辑像素，CSS 等比放大 `clamp(min((vw−32)/960,(vh−32)/560), 0.6, 1.6)` | 左上信息卡 / 顶部关卡名 / 右上小地图 / 底部单行工具栏（与改造前逐像素一致） |
| `portrait` | `vw ≤ 600` 且 `vh > vw` | 原生 CSS 像素（不缩放，字号=CSS px），视野宽 **480~620** 世界单位 | 顶部信息条（4 个 40×40 触屏按钮）→ 中部战场（裁切）→ 底部工具栏（5 列多行，按钮 ≥44px） |
| `compact` | `vw > vh` 且 `vh ≤ 560` | 宽 960 世界单位恒定，纵向按高度裁切并居中 | 左上信息卡 + 关卡名居中 + 右上小地图；菜单页「标题在左、按钮竖排在右」 |

关键不变量（验证器逐分辨率断言）：

- `VIEW` 是**世界坐标 → 画布矩形**的唯一等比映射：`rect.w === VIEW.w × VIEW.s`、`rect.h === VIEW.h × VIEW.s`，且 `rect` 永远完整落在 `band` 内（不溢出）
- 世界高度 `WORLD_H=560` 永不改变；地形/水位/雷暴光柱只认世界坐标
- 相机唯一入口 `camViewW()/camMaxX()/setCamX()/centerCamX()`，任何写入都会被钳制
- **布局函数化**：`layoutHUD()` / `layoutToolbar()` / `layoutLevels()` / `layoutDifficulty()` / `uiButtons()` 同时供「绘制」与「命中」消费，看到的就是点得到的
- **指针状态机**：`idle → aiming / panning`，8 CSS px 内抬指＝点按、超出＝拖拽；触屏在空白处拖拽平移镜头，鼠标保留贴边滚动
- 安全区：`#sa` 探针读取 `env(safe-area-inset-*)`，刘海屏与手势条不会被按钮压住

实测（`node tools/verify-mutiny.js` 的 `[21]` 组，11 种分辨率）：

## 技术要点

- 单文件 HTML（CSS + JS），IIFE 封装零全局变量，Canvas 全量重绘
- **Terrain 双层 + 材质平行层**：`Uint8Array data` 为碰撞权威、`Uint8Array mat` 记材质（供破坏掉落）、离屏 canvas 仅渲染
- **弹簧瞄准统一交互**：`slingDir()` 单一方向函数，发射/预览/AI 换算共用
- **回合管线**：`input → resolve（等投射物/飞行单位全部结算）→ 对方回合`；`resolveKind` 区分移动/攻击结算；三重防死锁保险丝
- **确定性随机**：`setRng(fn)` 可注入 RNG，使概率型机制可被无头验证
- **动态水位**：所有水面判断走 `waterY()`（读 `G.waterY`），涨潮机关只改这一个值
- **响应式三档 + 视口映射**：`detectMode/calcLayout/syncView` 产出 `L`（布局）与 `VIEW`（世界视口）；世界层 `setWorldTransform()` 一次性完成「世界→画布」映射，UI 层 `setScreenTransform()` 只管逻辑像素，两层互不污染
- WebAudio 合成音效，无外部资源
