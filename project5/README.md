# 数独 · Sudoku

一个零依赖、单文件的经典数独网页游戏，双击 `sudoku.html` 即可离线游玩。

![Sudoku](https://img.shields.io/badge/依赖-零-blue) ![License](https://img.shields.io/badge/license-MIT-green)

## ✨ 特性

- 🔢 谜题实时生成：随机化回溯生成终盘 + 挖洞法出题，**每一步挖洞都校验解仍唯一**（保证唯一解）
- 🎚 三档难度：简单（40 提示）/ 中等（31 提示）/ 困难（26 提示），求解器用 MRV 剪枝，生成均在 20ms 内
- ✏ 笔记模式：格内 3×3 铅笔备注，填数后自动清理同行/列/宫的相关笔记（可撤销）
- 💡 提示 ×3：填入正确答案并高亮；未选中格子时随机挑空格提示
- 🎨 智能高亮：选中格的同行/列/宫底色、同数字高亮、行列宫重复冲突标红
- ↩ 撤销（含笔记与提示的完整快照，最多 300 步）
- ⏸ 暂停（棋盘模糊防偷看 + 计时停止）、计时、各难度最佳时间记录（localStorage）
- 🔢 数字面板：每键显示该数字剩余可填数量，填满 9 个自动变暗
- 🔊 WebAudio 实时合成音效（填数/笔记/冲突/提示/通关），可一键静音
- 📱 响应式布局，窄屏自动换行、触屏可玩
- ⚡ 零依赖，单 HTML 文件，无需安装

## 🕹 操作

| 按键 / 操作 | 功能 |
| --- | --- |
| 点击格子 | 选中（方向键可移动） |
| 1-9 | 填数 / 笔记模式下写备注（再按一次取消填数） |
| Del / 退格 / 0 | 擦除选中格 |
| N | 切换笔记模式 |
| H | 提示 |
| Z | 撤销 |
| P | 暂停 |
| 侧栏难度按钮 | 切换难度并开新局 |
